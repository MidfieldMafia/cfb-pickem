# Live Board: last play, possession and the game sheet (prototype, throwaway)

This is the Claude Design canvas for "Live Board: show last play and down-and-distance" (#209) and "Live Board: show which team has the ball" (#208). It also holds the first design of the richer game sheet, which is charted as its own roadmap. Canvas: https://claude.ai/artifact/N1JEr7MdjGzpte9H2xtikV (private to Jonah's account).

These are the canvas files (`*.dc.html`, `canvas.json`) as published after Jonah's edits on 2026-09-23. The images are assets on the canvas, not files here. Never merge this branch.

- `Mixed.dc.html` + `Game.dc.html`: the chosen Live Board row (#208, #209).
- `SheetLive.dc.html`: the live-game sheet, which is playable. Its Tweaks choose a drive, a touchdown, a field goal, a safety or one play; also the score count-up and the direction marker.
- `SheetFinal.dc.html`: the final-game sheet with team stats and game leaders.
- `Main`, `OptionA/B/C`, `States`, `Sheet`: the earlier rounds and the alternatives, kept for reference.
